# 🏛️ CivicFlow Frontend

The frontend interface for CivicFlow, a resilient digital public infrastructure layer.

## 🚀 Built With
- **React 19**
- **Vite**
- **Tailwind CSS v4**
- **IndexedDB & Workbox** (for offline persistence)

## 🛠️ Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment:
   ```bash
   cp .env.example .env
   # Update VITE_API_URL if your backend is not on localhost:4000
   ```

3. Run development server:
   ```bash
   npm run dev
   ```
